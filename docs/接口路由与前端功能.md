# 接口路由与前端功能

这是一份面向开发和联调的接口字典，只说明：路由、功能、所需数据、对应前端功能。

说明：`Path` 是路由中的 `{参数}`，`Query` 是 URL 查询参数，`Body` 是 JSON 请求体；字段后的 `?` 表示可选。

## 登录与用户资料

| 方法 | 路由 | 功能 | 需要的数据 | 对应前端功能 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/auth/register` | 注册普通用户 | Body：`username,password,displayName?` | 登录注册页 |
| POST | `/api/v1/auth/login` | 登录并签发令牌 | Body：`username,password` | 登录页 |
| POST | `/api/v1/auth/refresh` | 刷新访问令牌 | Body：`refreshToken` | 请求模块自动续期 |
| POST | `/api/v1/auth/logout` | 退出并撤销刷新令牌 | Body：`refreshToken` | 顶部“退出” |
| GET | `/api/v1/users/me` | 获取当前用户资料 | 无 | 顶部用户信息、个人页 |
| PATCH | `/api/v1/users/me` | 修改当前用户资料 | Body：`displayName?,avatarUrl?,bio?,region?` | 个人页“编辑资料” |

## 智能问答与会话

| 方法 | 路由 | 功能 | 需要的数据 | 对应前端功能 |
| --- | --- | --- | --- | --- |
| POST | `/api/v1/conversations` | 创建问答会话 | Body：`title` | 当前由首次提问自动创建，前端不单独调用 |
| GET | `/api/v1/conversations` | 查询会话列表 | Query：`limit?` | 智能问答左侧“会话历史” |
| POST | `/api/v1/conversations/{conversationId}/messages` | 向会话写入消息 | Path：`conversationId`；Body：`role,content,modelName?,tokenCount?` | 由问答流程自动保存，前端不单独调用 |
| GET | `/api/v1/conversations/{conversationId}/messages` | 查询会话历史消息 | Path：`conversationId` | 点击历史会话后加载消息 |
| POST | `/api/v1/chat/preview` | 非流式生成回答 | Body：`question,conversationId?,petProfileId?,petType?,category?` | 智能问答普通请求/降级请求 |
| POST | `/api/v1/chat/stream` | SSE 流式生成回答 | Body：预览参数加 `requestId` | 智能问答“发送”，逐字显示结果 |
| DELETE | `/api/v1/chat/streams/{requestId}` | 停止流式回答 | Path：`requestId` | 智能问答“停止生成” |

| GET | `/api/v1/community/posts` | 分页查询社区信息流 | Query：`feed?,topicId?,authorId?,latitude?,longitude?,radiusKm?,page?,size?` | 社区页最新、热门、关注、附近信息流 |
